# Jarvis 任务书存档

本目录 = pi-web fork 的**任务书真相源**（What + Why，随代码走）。规范出处：second-brain `[[委托编码工作流]]`（skill `delegate-coding` 的设计真相源）。

## 命名

`YYYYMMDD-<kebab-slug>.md`，一任务一文件，不改动历史文件（升版直接改原文并更新 `version`）。

## 生命周期

`draft`（深挖中，决策随时追加）→ `frozen`（冻结发出）→ `done`（收口：验收+部署+second-brain 记录后）/ `aborted`（放弃，留案）。

## 与 second-brain 项目笔记的分工（不重复）

| 内容 | 归属 |
|---|---|
| 需求原文、深挖问答、决策 D1..Dn+理由、验收标准、改动白名单、实现中回流的需求级问答 | 任务书（本目录） |
| 项目进度总览、跨任务教训、架构级决策 | second-brain `[[pi-web 定制 Fork]]` |
| 单任务详情 | 任务书；项目笔记只留一行指针+状态 |

一句话：**任务书=单任务的完整生平；项目笔记=项目仪表盘，只放指针和跨任务沉淀。**

## 敏感性

本 fork 在 GitHub 上是公开 fork（暂不推送，但随时可能推）。任务书内容保持**可公开级**：个人体系细节（备份链/设备拓扑等）引用 second-brain 笔记名，不内联；凭据绝不出现。
